# The Dragon Tool en GitHub

## Subir (una sola vez)
1. En github.com crea un repositorio **publico** llamado `TheDragonTool`.
2. Sube estos 4 archivos a la raiz: `TheDragonTool.ps1`, `logo.png`, `iniciar.ps1`, `.gitattributes`
   (boton Add file > Upload files; para actualizar la herramienta, vuelve a subir `TheDragonTool.ps1`).
3. Abre `iniciar.ps1` en GitHub (lapiz de editar) y cambia las 2 veces que dice `TU_USUARIO` por tu usuario de GitHub.
